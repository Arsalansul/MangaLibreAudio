# AudioManga

Локальная сборка озвученной главы манги из готовых страниц и файлов
`*.analysis.json`, создаваемых переводчиком манги.

## Веб-интерфейс

Запустите двойным щелчком `start.bat` или из терминала:

```powershell
.\start.bat
```

Можно сразу передать папку главы:

```powershell
.\start.bat "E:\MangaTranslateProjects\Bleach\out\chapter"
```

Интерфейс открывается по адресу `http://127.0.0.1:8765`. В нём можно выбрать
папку, настроить текст, голос, персонажа, темп, высоту и паузы каждой реплики,
добавлять и удалять реплики, сохранить сценарий и запустить сборку видео.

## F5-TTS и клонирование голоса

F5-TTS устанавливается отдельно, чтобы его тяжёлые зависимости не влияли на
быстрый режим Silero:

```powershell
.\install-f5.bat
```

На компьютере с NVIDIA вместо этого используйте:

```powershell
.\install-f5-nvidia.bat
```

Этот установщик ставит совместимую CUDA-сборку PyTorch; отдельный CUDA Toolkit
не нужен, достаточно актуального драйвера NVIDIA. Для локального F5 требуется
Python 3.11. Если его нет, установите `winget install --id Python.Python.3.11 -e`
и повторно запустите установщик.

После установки выберите у реплики движок `f5` и укажите референсное аудио.
Точная расшифровка речи в нём улучшает результат, но поле можно оставить пустым:
тогда F5-TTS расшифрует запись автоматически через Whisper. При первом таком
запуске загрузится дополнительная ASR-модель, поэтому он будет заметно дольше.
Рекомендуется чистая запись одного человека без музыки и шумов. Знаки `+` для
ударений относятся только к Silero и перед передачей текста в F5 удаляются.
Параметр `speed` принимает значения `0.3–2.0`, а `NFE` —
`4–64`: больше шагов обычно медленнее. На Windows с AMD-видеокартой F5-TTS
работает через CPU. На проверенной конфигурации короткая фраза с `NFE=16`
занимает около 50 секунд; повторные реплики берутся из кеша.

Русский checkpoint `hotstone228/F5-TTS-Russian` и vocoder автоматически
загружаются при первой F5-сборке в `.runtime/huggingface`. Модель опубликована
под лицензией CC BY-NC-SA 4.0: она предназначена для некоммерческого применения с
указанием авторства. Используйте только голоса и записи, на которые у вас есть
разрешение.

### Где выполнять F5-TTS

В верхней части редактора доступны три режима:

- `Локально · CPU` — совместимый, но медленный режим;
- `Локально · NVIDIA CUDA` — использует NVIDIA на этом компьютере без Worker;
- `Удалённый F5 Worker` — отправляет реплики на другой компьютер по HTTP.

После изменения `requirements-f5.txt` повторно запустите `install-f5.bat` — для
русской модели используется совместимая версия F5-TTS `1.1.7`.

## Удалённый F5 Worker

Worker запускается отдельно на компьютере, который будет синтезировать речь.
CPU-вариант:

```powershell
docker compose -f compose.f5-worker.yml --profile cpu up --build
```

NVIDIA-вариант:

```powershell
docker compose -f compose.f5-worker.yml --profile nvidia up --build
```

Модели сохраняются в Docker volume и не скачиваются после каждого перезапуска.
В AudioManga выберите `Удалённый F5 Worker`, введите адрес наподобие
`http://192.168.1.50:8770` и нажмите `Проверить`. Оба компьютера должны видеть
друг друга в локальной сети, а TCP-порт 8770 должен быть разрешён брандмауэром.
Подробности API находятся в `worker/README.md`.

## Формат входной папки

Для каждой страницы должны находиться два файла с одинаковым именем:

```text
0006.png
0006.analysis.json
```

Текст берётся из `regions[].translation`. Страницы без готового изображения
пропускаются с предупреждением.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
python audiomanga.py build "E:\MangaTranslateProjects\Bleach\out\chapter"
```

Если `.venv` уже создано, обычный системный Python автоматически перезапустит
команду через окружение AudioManga. Активировать окружение перед каждым запуском
необязательно.

Первый запуск создаёт рядом со страницами файл `audiomanga.project.json`.
Перед повторным запуском в нём можно менять порядок реплик, текст, голос и флаг
`speak`. Аудио кешируется в `.audiomanga/audio`, результат сохраняется как
`chapter.mp4`.

По умолчанию используется собственная модель AudioManga
`.runtime/models/v5_4_ru.pt` и голос `aidar`. Проект не обращается к файлам
других приложений. Альтернативы:

```powershell
python audiomanga.py build "ПАПКА" --voice xenia
python audiomanga.py build "ПАПКА" --model "D:\Models\v5_4_ru.pt"
python audiomanga.py build "ПАПКА" --ffmpeg "D:\Tools\ffmpeg\bin\ffmpeg.exe"
```

## Интонация и паузы

У каждой реплики в `audiomanga.project.json` есть отдельный текст для
произношения и настройки SSML:

```json
{
  "text": "Я тебя вижу...",
  "tts_text": "Я тебя в+ижу...",
  "voice": "aidar",
  "prosody": {
    "rate": "slow",
    "pitch": "low",
    "pause_before_ms": 150,
    "pause_after_ms": 400
  }
}
```

Допустимый темп: `x-slow`, `slow`, `medium`, `fast`, `x-fast`; высота:
`x-low`, `low`, `medium`, `high`, `x-high`. Знак `+` перед ударной гласной
задаёт ручное ударение. Поле `text` можно оставить без изменений — озвучивается
`tts_text`.

`--refresh` заново формирует сценарий из файлов анализа и удаляет из него
ручные изменения.

## FFmpeg

Нужна готовая Windows-сборка с файлом `ffmpeg.exe`. Исходный репозиторий FFmpeg
сам по себе не содержит исполняемого файла. По умолчанию проверяются `PATH`,
переменная `AUDIOMANGA_FFMPEG` и путь `E:\ffmpeg\bin\ffmpeg.exe`.
